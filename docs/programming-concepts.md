
# Programming Concepts Implemented

## Project Title
Smart Campus Operations and Emergency Response Management System in C++

## 1. Decision-Making Statements
- if statements
- if-else statements
- nested if conditions
- switch statements
- Input validation using conditional statements

## 2. Loops
- for loops
- while loops
- do-while loop
- Nested loops for displaying the campus resource matrix

## 3. Functions
- Functions without parameters and without return values
- Functions with parameters and without return values
- Functions without parameters and with return values
- Functions with parameters and with return values
- Recursive function for counting high-priority requests
- Function overloading using displayRequest()

## 4. Arrays
- One-dimensional array for storing campus requests
- Two-dimensional array for campus resource usage

## 5. Structures
- Request structure
- Location structure nested inside Request
- Passing structures by value
- Passing structures by reference

## 6. Pointers and Dynamic Memory
- Pointer declaration and usage
- Dynamic memory allocation using new
- Dynamic memory deallocation using delete[]
- Safe memory handling

## 7. Strings
- Student names
- Departments
- Request categories
- Descriptions
- Staff names
- Building and room information

## 8. File Handling
- Writing records using ofstream
- Reading records using ifstream
- Processing records using stringstream
- Saving and loading request records

## 9. Input Validation and Error Handling
- Empty input validation
- Invalid menu choices
- Invalid request IDs
- Invalid priority values
- Duplicate request ID handling while loading
- Invalid file record handling
- Maximum request storage validation

## 10. Main System Features
1. Submit New Request
2. View All Requests
3. Search Request
4. Update Request Status
5. Assign Staff
6. Close Request
7. Emergency Management
8. Generate Reports

The project demonstrates the major C++ programming concepts required in the assignment through a practical Smart Campus Management System.
