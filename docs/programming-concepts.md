# C++ Programming Concepts Used

## 1. Conditional Statements
- if statements
- if-else statements
- Nested decision-making
- switch statements

## 2. Loops
- for loops
- while loops
- do-while loops

## 3. Functions
- Functions with parameters
- Functions without parameters
- Functions with return values
- Function overloading

## 4. Recursion
The system uses a recursive function to count high-priority requests.

## 5. Arrays
The system uses a one-dimensional array to store request records.

## 6. Structures
The Request structure stores student information, request details, priority, status, and assigned staff.

## 7. File Handling
The system uses file handling to save and load request records through requests.txt.

## 8. Strings
The string data type is used to store names, departments, categories, descriptions, and other text information.

## 9. Input Validation
The system checks invalid menu choices, empty fields, and invalid priorities.
