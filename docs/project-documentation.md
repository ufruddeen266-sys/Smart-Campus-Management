# Project Documentation

## 1. Introduction
The Smart Campus Operations and Emergency Response Management System is developed to manage campus-related requests and emergencies through a C++ menu-driven application.

## 2. Main Modules
- Request Submission
- Request Viewing
- Request Searching
- Status Management
- Staff Assignment
- Request Closure
- Emergency Management
- Report Generation

## 3. Request Status
- Pending
- In Progress
- Resolved
- Closed

## 4. Emergency Categories
- Medical
- Fire
- Electrical
- Security

## 5. Data Management
The system uses file handling to save and retrieve request records through a text file named `requests.txt`.

## 6. Error Handling
The application checks invalid menu choices, empty required fields, invalid priorities, and unavailable request IDs.

## 7. Future Improvements
- Dynamic memory allocation
- Two-dimensional arrays
- Nested structures
- Improved input validation
- Advanced campus resource management
