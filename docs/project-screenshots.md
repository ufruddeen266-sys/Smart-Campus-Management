Smart Campus Operations and Emergency Response Management System
Project Screenshots Documentation
1. Introduction
This document presents screenshots of the Smart Campus Operations and Emergency Response Management System developed using C++.
The screenshots demonstrate the main menu, request submission, request viewing, request searching, status updates, staff assignment, emergency management, and report generation.
2. Main Menu
The main menu provides access to all major operations of the system.
Available options:
•	Submit New Request
•	View All Requests
•	Search Request
•	Update Request Status
•	Assign Staff
•	Close Request
•	Emergency Management
•	Generate Reports
•	Exit
